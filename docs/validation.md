# 验证范围

`bash tests/run.sh` 核对源码发布清单及两份重建 bundle，运行 Python 清理/部署保护/错误上游测试与 Node.js 实际方法模拟。所有数据为临时目录和合成任务，无真实账号、房间、投稿或生产连接。

清理覆盖默认保留失败/成功删除、显式失败删除、取消、重试、父子/兄弟状态、handled/raw回调、API失联/重启、已持久终态、缺失非终态、重复/崩溃恢复、文件替换/symlink/硬链接、删除失败退避、开放FD/扫描失败和删除意图后身份变化。调度覆盖同一直播串行、不同直播并行、handled/raw双向请求、全类型请求、异常解锁、后处理立即调度且不等待上传。上传流覆盖成功、失败、有限重试、取消及限速异常，检查实际流 closed/destroyed。

CI 从固定上游镜像提取原始文件，构建与 SHA256 校验后执行 Python/Node 测试、语法/Compose/systemd验证、Gitleaks目录与全历史及禁止文件扫描。CI 没有生产凭据、SSH 或部署步骤。

本公开版本**尚未通过真实直播完整端到端验证**，也未在本轮从零安装到真实新主机：安装器的系统变更、真实账号登录、Webhook接收、5 GiB连续分段、取消/网络中断、稿件分P/合并及最终删除仍需独立环境验证和自然直播观察。生产祖先版本的运行或离线模拟不能替代新补丁验证。维护窗口执行与实际回滚本轮未演练。

已知边界：秒级命名仍有同秒冲突；网络EOF/404/TLS可继续发生；上游原生成功删除先于旁路清理，不受本清理器全部保护；stat/FD/unlink间存在并发窗口，目录须仅有受信任写入者；任务缺失或回调未结束的持久记录可能保守阻止清理，需要人工核对，不能清台账解决。

上线观察步骤：自然开播→中文秒级文件增长→约5 GiB分段且下一文件继续增长→关闭后安排上传→有限重试保留→稿件最终成功/显式失败策略→回调和FD结束→文件及占用释放→分P顺序与合并正确。不要主动在生产断网或伪造事件。
